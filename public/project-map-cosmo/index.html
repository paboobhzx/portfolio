Project Context + Objective

COSMOFIT centralizes the full training lifecycle in one cloud platform: account onboarding, workout operations, catalog governance, session tracking, and billing-driven entitlement control.

Architecture Overview

  • Frontend hosted in Amplify with CloudFront and custom routing.
  • HTTP APIs split between product and admin surfaces.
  • Domain-oriented Lambda handlers with shared layers and IAM boundaries.
  • DynamoDB, Cognito, and S3 as the core managed data plane.

End-to-End Flow

  • User signs in through Cognito and accesses tenant-scoped UI.
  • Frontend calls API Gateway routes protected by JWT authorizers.
  • Lambda functions read/write catalog, sessions, and account state in DynamoDB.
  • AI workflows enrich workout generation using predefined templates and cache context.
  • Payments/webhooks update plan entitlements and access paths.

Stack + Key Services

React frontend, AWS Amplify, API Gateway v2, Lambda (Python), DynamoDB, Cognito, S3, CloudFront, Route53, Terraform modules for foundation/data/auth/compute/frontend.

Delivery Metrics / Scale Indicators

  • Infra is Terraform-first with production safety controls and reusable modules.
  • Handlers are organized by business domain (sessions, workouts, analytics, billing, media).
  • Catalog/workout automation scripts support continuous data enrichment operations.

Engineering Decisions + Tradeoffs

  • Serverless architecture reduces baseline ops effort, but requires disciplined monitoring and tracing.
  • Function-per-domain boundaries improve isolation with higher deployment surface area.
  • Automation-heavy content workflows accelerate delivery while increasing pipeline governance needs.
