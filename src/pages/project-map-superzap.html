02 // The Architecture

03 // The Multi-Tenancy Challenge

Building a WhatsApp CRM for multiple tenants on a single codebase requires bulletproof tenant isolation, real-time message delivery, and the ability to handle message bursts without dropping conversations.

terminal Engineering Insight

"Every tenant thinks they're the only user on the platform. That's the goal — complete isolation with shared infrastructure economics."

04 // Key Engineering Decisions

Data Architecture

Tenant Scoping

All database queries are scoped to the authenticated tenant via a mandatory tenant_id filter at the application layer. MySQL tables include tenant_id on every row — no cross-tenant data leakage is possible.

Real-Time Engine

WebSocket + Event Queue

Messages arrive via WhatsApp webhook, enter a Redis-backed queue, and are delivered to operators in real-time via WebSocket. No polling, no missed messages.

Conversation Routing

Intelligent Assignment

Conversations are automatically routed to available operators based on department, skills, and current load. Managers can reassign via the Kanban board in real-time.

Operational Tooling

Manager Dashboard

Full operational visibility with live KPIs, agent performance metrics, lead pipeline tracking, and configurable reports. Managers control everything without touching code.

Collaboration

Operator-to-Operator Transfers

Managers can transfer conversations between operators. The receiving agent sees a visual banner with a countdown and can return the conversation with a note.

Visibility

Manager Notifications

Real-time notification bell for managers. Receives alerts for help requests, conversation returns, and key operational events — with toast popups and unread badge.

Real-Time

Presence Indicators

Live contact status in the chat header: online, typing, recording audio, or last seen X minutes ago. Fetched on open, updated via WebSocket in real time.

Trust & Safety

Blocked Numbers

Block contacts from sending or receiving messages. Inbound messages are silently discarded at the webhook level — before any conversation is created.

Productivity

Global Search

Search across all conversations by contact name or message content. Accessible via Ctrl+K — results update as you type.

Design

Unified Design System

Consistent visual identity across all views with switchable themes. CSS token system shared between operator and manager interfaces.
