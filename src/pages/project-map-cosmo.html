01 // The Architecture

Cosmo is built serverless-first on AWS. A React/TypeScript SPA communicates with a suite of AWS Lambda functions behind API Gateway. DynamoDB stores user profiles, workout history, and achievement data. AWS Cognito handles authentication. AWS Bedrock (Nova Pro) generates AI workout plans from user inputs — goals, fitness level, available equipment.

02 // The AI Integration Challenge

Integrating a large language model into a fitness app requires more than an API call. The prompt engineering needed to produce safe, structured, periodized workout plans — with correct sets, reps, and progressive overload — took significant iteration. The output also needed to be parsed reliably into a data schema the frontend could render, not just raw text.

terminal Engineering Insight

"The hardest part wasn't the AWS integration — it was making the LLM output consistent enough that the UI could render it deterministically."

03 // Key Engineering Decisions

AI Layer

Bedrock + Nova Pro

AWS Bedrock abstracts the model provider. Nova Pro was chosen for its structured output support — critical for generating machine-readable workout JSON from natural language prompts without post-processing hacks.

Auth Strategy

Cognito Identity Pools

AWS Cognito handles user sign-up, sign-in, and JWT issuance. Lambda functions validate tokens server-side — no custom auth logic required. The same auth layer serves both the web app and the iOS companion app.

Data Model

DynamoDB Single-Table

A single DynamoDB table with GSI access patterns covers users, workout history, achievements, and calendar entries. Pay-per-request billing fits the usage profile of a fitness app — spiky, not constant.

Mobile Companion

iOS + SwiftUI

COSMOFIT (iOS 16+, SwiftUI) is a companion app sharing the same AWS backend. Puppeteer-based E2E tests cover the web flows; native iOS testing (XCTest) covers the mobile layer separately.
