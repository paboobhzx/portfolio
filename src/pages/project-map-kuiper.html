01 // The Architecture

Kuiper is a fully serverless document intelligence pipeline. A user uploads a PDF via the React frontend to S3. A Step Functions state machine kicks off: Lambda triggers Textract for OCR, the extracted text chunks are indexed into a Bedrock Knowledge Base, and the document becomes queryable via a Nova Pro-powered chat interface.

02 // The RAG Reliability Challenge

Building a document Q&A system that actually answers questions from the document — and not from the model's training data — requires careful chunking strategy, embedding quality, and retrieval tuning. The Bedrock Knowledge Base handles embedding and vector search, but the chunking and prompt design that keeps answers grounded took real iteration.

terminal Engineering Insight

"The model knows everything. The hard part is making it answer only from your document — not from what it already knew."

03 // Key Engineering Decisions

Orchestration

Step Functions State Machine

The ingestion pipeline — upload, OCR, chunk, embed, index — is orchestrated as a Step Functions state machine. Each step is a discrete Lambda. If Textract fails, only that step retries. The pipeline is observable, restartable, and decoupled.

Document Intelligence

Textract for OCR

AWS Textract handles multi-page PDFs including scanned documents and tables. Unlike basic PDF-to-text libraries, Textract preserves layout context and handles handwritten content — important for enterprise use cases with legacy document formats.

AI Layer

Bedrock Knowledge Base + RAG

Bedrock Knowledge Base manages the vector embeddings and similarity search. The chat Lambda retrieves relevant chunks and injects them into the Nova Pro prompt — grounding answers in the document. Hallucination is structurally constrained, not just prompted against.

Infrastructure

Full Terraform IaC

Every resource — S3 bucket, Lambda functions, Step Functions state machine, IAM roles, Bedrock Knowledge Base, API Gateway — is defined in Terraform. The entire stack stands up from zero with a single apply. No manual console configuration.
